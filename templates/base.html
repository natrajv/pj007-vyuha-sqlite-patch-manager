This SQLite patch manager compares a Patch database with a Base database, identifies schema and data differences, and helps apply controlled database changes.

It provides schema validation, CRUD change analysis, configurable patch options, detailed change inspection, and a downloadable merged SQLite database.

Features
  1. Compare Patch and Base SQLite databases.
  2. Automatically detect schema mismatches.
  3. View detailed schema comparison reports.
  4. Detect tables, columns, and row additions, changes, and deletions.
  5. Configure structure, row deletion, and row update patch options.
  6. Inspect table-level and row-level changes.
  7. Filter Tables using change type and wildcard table-name searches.
  8. Paginate large Tables lists using configurable page size.
  9. Merge selected Patch changes into a copy of the Base database.
  10. Download the resulting SQLite database.
